# Features

## Existing, verified functionality

No screens, records, integrations or product features exist.

## Proposed functionality

| Feature | Scope and acceptance criteria |
| --- | --- |
| Dashboard | Recent records and descriptive totals linked to their sources; honest empty states |
| Symptom logger | Occurrence date/time, symptom, severity, optional note; confirmation only after persistence |
| Timeline | Filter, inspect, edit, delete; timezone visible and dependent views refreshed |
| Menstrual tracking | Optional bleeding records; skippable without fertility or regular-cycle assumptions |
| Journal | Private dated text, safe rendering, explicit save/error status |
| Education | Sources, named review responsibility and review date on every published resource |
| Observations | Versioned rules showing counts, coverage, source entries and limitations |
| Appointment preparation | Selected records, questions, preview and export; facts separated from observations |
| Privacy controls | Purpose-specific consent, correction, export and deletion progress |

Synthetic previews must be labeled and must not collect real health information. Real-user logging requires verified authentication, owner isolation and secure persistence. Wearables, clinician sharing, predictions and generative chat are deferred proposals.

## Decisions still needed

Symptom vocabulary, severity scale, cycle scope, export formats, reminders, offline needs and resource publishing workflow.
